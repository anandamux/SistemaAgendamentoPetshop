# Sistema de Agendamento - Pet Shop

Sistema web desenvolvido para gerenciar agendamentos de banho e tosa em um Pet Shop. O projeto conta com uma interface para o cliente escolher horários disponíveis e um painel administrativo protegido por senha para controle de capacidade e visualização da agenda.

## 💻 Tecnologias Utilizadas

* **Backend:** Node.js, Express
* **Frontend:** Handlebars (HBS), CSS3, HTML5
* **Banco de Dados:** MongoDB
* **Arquitetura:** MVC (Rotas, Controladores, Views) 

## 🚀 Como rodar o projeto localmente

Certifique-se de ter o **Node.js** e o **MongoDB Compass** instalados na sua máquina.

1. Clone este repositório:
```
git clone [https://github.com/SEU-USUARIO/sistema-agendamento-petshop.git](https://github.com/SEU-USUARIO/sistema-agendamento-petshop.git)
```

1. Entre na pasta do projeto:
   ```
   cd sistema-agendamento-petshop
   ```
2. Instale as dependências:
    ```
   npm install
    ```
3. Inicie o servidor web:
    ```
   node index.js
    ```
5. Acesse à aplicação no navegador através do endereço ``http://localhost:3000.``
